# Démos

*Trois applications, un broker MQTT, aucun backend — tout le flux en quelques minutes.*

Chaque démo montre trois applications Hecate réelles côte à côte : **Admin** crée et publie un profil, **Capture** le récupère depuis le broker et enregistre un objet, et **Viewer** affiche le profil et l'asset en direct — pas de serveur, seulement MQTT.

!!! note
    Le texte à l'écran est en allemand ; le déroulé se comprend de lui-même.
