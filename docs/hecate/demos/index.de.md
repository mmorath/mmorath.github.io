# Demos

*Drei Apps, ein MQTT-Broker, kein Backend — der ganze Ablauf in wenigen Minuten.*

Jede Demo zeigt drei echte Hecate-Apps nebeneinander: **Admin** legt ein Profil an und publiziert es, **Capture** übernimmt es vom Broker und erfasst ein Objekt, und **Viewer** zeigt Profil und Asset live — kein Server, nur MQTT.
