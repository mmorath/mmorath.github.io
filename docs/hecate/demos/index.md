# Demos

*Three apps, one MQTT broker, no backend — the whole flow in a few minutes.*

Each demo runs three real Hecate apps side by side: **Admin** authors and publishes a profile, **Capture** picks it up from the broker and records an object, and **Viewer** shows the profile and the asset live — no server, only MQTT.

!!! note
    The on-screen narration is in German; the flow speaks for itself.
