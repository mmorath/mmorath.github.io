# Frameworthy

Frameworthy ist eine Mac-App, die Aufzeichnungen zum Teilen vorbereitet: Sie
konvertiert ein Video, ergänzt einen Titel- und einen Klassifizierungsbalken mit
eigener Schrift und eigenem Logo, erkennt den gesprochenen Text, übersetzt
Untertitel, schlägt Kapitel vor und teilt das Ergebnis in Teile unter einer
Größengrenze — **vollständig auf deinem Mac**.

- Benötigt macOS 26 oder neuer auf einem Mac mit Apple Chip.
- Textkorrektur und Kapiteltitel nutzen Apple Intelligence (auf dem Gerät).
- Erhältlich im Mac App Store.
