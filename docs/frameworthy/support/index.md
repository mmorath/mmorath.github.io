# Support — Frameworthy

## Requirements

- macOS 26 or newer on a Mac with Apple silicon.
- **Apple Intelligence** turned on (System Settings › Apple Intelligence & Siri) for
  text correction and chapter titles. Everything else works without it; the app
  explains when it is off.

## Frequently asked questions

**Where are my converted videos?**
In the output folder shown in the window (default: `Movies/Frameworthy`).
File › Show Output Folder in Finder opens it.

**The app says it lost access to a file or folder.**
macOS only lets the app open what you chose. If a file was deleted, moved to another
disk or its disk is not connected, choose it again (for example the output folder
with File › Choose Output Folder …).

**"Recognize Speakers" downloads something.**
The first time, the app downloads the speaker models (about 22 MB) from Hugging Face.
After that it works offline. No audio or other data is sent.

**Which fonts and logos can I use?**
The bold system font, or your own font file (TTF, OTF, TTC) and image file
(PNG, SVG, PDF, JPEG, HEIC). Make sure you are allowed to use the font and logo you
burn into your videos.

**Where is the log?**
Help › Open Log Folder. Attach the relevant lines when you report a problem.
